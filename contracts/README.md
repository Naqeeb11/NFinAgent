# Contract Repository

Place versioned OpenAPI, AsyncAPI, JSON Schema, and data contracts here. Contract changes require tests, compatibility notes, and an ADR when they change ownership or safety boundaries.

Suggested structure:

```text
contracts/
  openapi/v1/
  asyncapi/v1/
  jsonschema/v1/events/
  jsonschema/v1/ledger/
  data-contracts/
```
